# Machine Learning Assignments

This repository contains solutions for a series of machine learning assignments covering various topics.

## Assignments

### Assignment 1: Pima Indians Diabetes Classification
- **Dataset:** [Pima Indians Diabetes Database](https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database)
- Tasks: Data preprocessing, KNN and Decision Tree classification, inference pipeline.

### Assignment 2: Stellar Classification and California Housing Regression
- **Datasets:** 
  - [Stellar Classification Dataset](https://www.kaggle.com/datasets/jsonali2003/stellar-classification-dataset)
  - [California Housing Prices](https://www.kaggle.com/datasets/camnugent/california-housing-prices)
- Tasks: Stratified splitting, classification report, confusion matrix, regression with Ridge/Lasso.

### Assignment 3: Feature Engineering and Hyperparameter Optimization
- **Datasets:** 
  - [Cat in the Dat II](https://www.kaggle.com/competitions/cat-in-the-dat-ii)
  - [Playground Series S3E8](https://www.kaggle.com/competitions/playground-series-s3e8)
- Tasks: Feature engineering, Grid-search, Random-search.

### Assignment 4: Ensemble Learning
- **Dataset:** M1 Competition Data
- Tasks: Apply various ensemble learning methods.

### Assignment 5: Text Classification
- **Dataset:** [SMS Spam Collection Dataset](https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset/data)
- Tasks: Text cleaning, Naive Bayes, Random Forest, XGBoost, ensemble methods.

### Assignment 6: SVM Classification
- **Dataset:** [Fashion MNIST](https://www.kaggle.com/datasets/zalando-research/fashionmnist)
- Tasks: SVM with linear, polynomial, and RBF kernels.

### Assignment 7: Dimensionality Reduction and Feature Selection
- **Datasets:** 
  - [Fashion MNIST](https://www.kaggle.com/datasets/zalando-research/fashionmnist)
  - M1 Competition Data
  - [Iris Dataset](https://www.kaggle.com/datasets/uciml/iris)
- Tasks: PCA, feature selection, K-Means clustering.
